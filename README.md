# 待办事项 Todolist

一个纯前端的待办事项管理应用，支持分组标签、搜索筛选、深色模式、数据备份与导入导出。打开浏览器即可使用，零依赖零配置。

## 功能特性

- **任务管理** — 添加、编辑、删除、标记完成，全部通过模态框交互
- **分组与标签** — 工作学习生活三分组 + 重要紧急日常三标签，彩色边框区分
- **搜索与筛选** — 实时关键词搜索（含高亮匹配），下拉框按分组/标签过滤
- **深色模式** — 一键切换，主题偏好自动持久化
- **数据安全** — 脏标记自动保存、多版本时间戳备份（保留最近 5 份）、JSON 导入导出
- **键盘快捷键** — `/` 聚焦搜索、`Esc` 清空、`Ctrl+Enter` 快速添加、`Ctrl+Shift+X` 切换完成
- **统计面板** — 任务总数/已完成/剩余/完成率 + 进度条可视化

## 架构

`script.js` 采用三层分离架构，所有常量集中在 `CONFIG` 对象管理：

```
CONFIG (常量配置)
  │
  ├── TaskStore (数据层)
  │     tasks[] 为唯一数据源
  │     负责增删改查、持久化、备份恢复、脏标记自动保存
  │
  ├── TaskRenderer (视图层)
  │     负责 DOM 渲染、统计面板、空状态、主题切换、搜索高亮
  │     不修改数据，不绑定事件
  │
  └── TaskController (控制层)
        负责事件绑定、业务流程、键盘快捷键
        所有数据变更后统一调用 handleFilter() 重渲染
```

核心原则：**数据驱动渲染** — Controller 修改 Store 数据后，统一通过 `handleFilter()` 重新渲染整个列表，不做手动 DOM 操作。

## 数据存储格式

```json
{
  "version": "1.0",
  "lastUpdated": "2026-05-26T10:30:00.000Z",
  "tasks": [
    {
      "id": "a1b2c3d4-...",
      "text": "完成周报",
      "group": "工作",
      "tag": "重要",
      "completed": false
    }
  ]
}
```

备份以 `tasks_backup_` + ISO 时间戳为键存储，自动清理超过 5 份的旧备份。

## 改进记录

### P0 安全修复
- XSS 注入：`innerHTML` 拼接替换为 `createElement` + `textContent`
- ID 重复：`Date.now()` 替换为 `crypto.randomUUID()`

### P1 架构优化
- 删除冗余 `add-task.html` 及路由判断逻辑
- 备份升级为多版本时间戳存储，保留最近 5 份
- Auto Save 改为脏标记机制，仅在数据变更时写入

### P2 三层重构
- 单体 `TodoApp` 拆分为 `TaskStore` / `TaskRenderer` / `TaskController`
- `CONFIG` 常量对象统一管理魔法字符串
- 确认弹窗改为事件委托，消除内存泄漏风险
- DOM 操作添加可选链判空保护
- 所有数据变更统一走 `handleFilter()` 重渲染
- 搜索关键词 `<mark>` 高亮
